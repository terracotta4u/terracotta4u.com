It has been a week since we released Golem, and development has not taken a single day of pause. The initial release of Golem gave users their own personal agent in a few clicks. However, these *clicks* were something we felt could be improved upon.

Initially a new user would have to download Golem, set up OpenRouter, go through the process of setting up a Telegram bot, then send their first message. We wanted to decrease this “time to first message.” To accomplish this we went after that last step: Telegram. 

Over the last week, we’ve designed and shipped a working web interface. Now a new user can immediately visit a link – hosted on their machine – and send their first message. This new chat interface has all of the features you would expect, and a few features that illustrate what makes Golem special. 

We are very proud of this web interface, and especially proud of our ability to quickly ship features. This velocity is in no small part thanks to AI development tools. However, we would like to highlight developer expertise as well. All of our code is reviewed by humans, all of our designs start with pen on paper. At Terracotta we aim to ship the best possible products. And this means thoughtfully designing every aspect, even if no one will ever see it.
